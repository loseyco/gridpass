GridPass Sim Racing Client
==========================

HOW TO INSTALL:
1. Extract ALL files from this ZIP to a folder (e.g. C:\GridPassClient).
   (Do not run from inside the ZIP file!)

2. Double-click "GridPass_Setup.bat".
   - This will check for Python and install it if needed.
   - It will install required libraries.
   - It will create a Desktop Shortcut.
   - It will launch the client.
   - It will open your Control Panel in the browser.

3. The client will connect to your GridPass account.
   Go to https://gridpass.app/sim-racing to see your device.

TROUBLESHOOTING:
- If Install.bat fails, try right-clicking and "Run as Administrator".
- Only Windows 10/11 is supported.
